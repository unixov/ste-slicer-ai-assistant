# STE Slicer AI Assistant

Плагин-ассистент для STE Slicer с чатом, встроенным непосредственно в интерфейс слайсера.

## Текущий статус

Первый вертикальный срез проекта включает:

- плагин формата STE Slicer/Cura API 5;
- отдельный stage `AI Assistant`;
- встроенную QML-панель в области sidebar;
- историю сообщений и поле ввода;
- кнопку анализа текущей модели;
- Python ↔ QML bridge;
- асинхронный OpenAI-совместимый HTTP-клиент без сторонних зависимостей;
- безопасные значения Base URL и модели без хранения API-ключа в исходниках.

Клиент LLM уже подключён к панели: сетевой запрос выполняется в отдельном Qt-потоке, а ответ или ошибка возвращаются в QML. MCP-инструменты, анализ прочности, heatmap и adaptive infill — следующие этапы разработки. Текущая панель намеренно не имитирует результаты физического расчёта.

## Установка в STE Slicer

1. Скопируйте папку `plugin/AIAssistant` в каталог пользовательских плагинов STE Slicer.
2. Запустите STE Slicer заново.
3. В списке этапов выберите `AI Assistant`.
4. В боковой панели появится чат.

Точный каталог можно открыть через меню слайсера «Справка → Показать папку конфигурации», затем открыть подпапку `plugins`.

## Настройка LLM

Значения по умолчанию:

- Base URL: `https://api.timeweb.ai/v1`
- Model: `dashscope/qwen3.8-flash`

Ключ не хранится в репозитории. Перед запуском слайсера задайте его локально:

```text
STE_SLICER_AI_API_KEY=<новый ключ организаторов>
```

При необходимости можно переопределить URL и модель:

```text
STE_SLICER_AI_BASE_URL=https://api.timeweb.ai/v1
STE_SLICER_AI_MODEL=dashscope/qwen3.8-flash
```

Не добавляйте ключ в `README.md`, Python-файлы, QML-файлы, Git-коммиты или публичные issue. Ключ, опубликованный на странице хакатона, следует считать скомпрометированным и заменить.

Текущая реализация отправляет `messages`, `model` и `temperature` в `/chat/completions`. Ответ читается из `choices[0].message.content`. Передача инструментов будет добавлена вместе с MCP-реестром.

## Совместимость

Код плагина пишется с учётом Python 3.5 и PyQt5 из дистрибутива STE Slicer. Не устанавливайте отдельную версию PyQt5 внутрь папки плагина.

Основная UI-интеграция использует QML stage extension, поскольку текущий STE Slicer создаёт sidebar через `SteSlicerStage.addDisplayComponent("sidebar", ...)`. `QDockWidget` и `QWebEngineView` для базовой панели не требуются.

## Ограничения текущей версии

- сообщение пока проходит через локальный bridge и получает демонстрационный ответ;
- API Chat Completions ещё не подключён к UI;
- MCP JSON-RPC и инструменты слайсера ещё не реализованы;
- анализ прочности пока не выполняется;
- heatmap и adaptive infill пока не реализованы;
- тестирование в Windows-дистрибутиве STE Slicer ещё требуется.
